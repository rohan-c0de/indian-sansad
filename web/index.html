Not built yet

This region is deliberately empty, and it is empty because a measurement gate failed — not because the work was skipped. The subject-search view is task T079.

A search result needs the question record, and the smallest published file containing one is a whole session partition. Measured against the real data: showing the first 25 results for a common word costs the index plus one session partition — 4,348,529 bytes, 3.9% over the first-load budget — and a two-word query that spans two sessions costs 7,236,751 bytes, 73% over. Shipping it would quietly cut the sustainable audience, so it was stopped and referred to the owner rather than shipped.

The index itself is fine, and has not been requested: it is published as one file (search/subject-index.json, 2.37 MiB) fetched on the first search only, so a visitor who never searches never downloads it.
